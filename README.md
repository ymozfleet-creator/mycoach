# コサポ — 学生アスリート × 個人スポンサー マッチングサービス

学生アスリートが戦績・トレーニング結果・動画・SNSで実力をアピールし、企業が「チェック（目星）」して事務局経由で年間スポンサー契約につなげるマッチングサービス。運営：RELIGHT

## リポジトリ構成

```
cosapo/
├── index.html    # ランディングページ（サービス紹介・料金・競合比較・FAQ）
├── app.html      # 本番アプリ（Supabase接続：認証・審査・チェック・フィード・支援相談）
├── demo.html     # スタンドアロンデモ（Supabase不要・ブラウザ保存。営業デモ用）
├── db/
│   └── cosapo_schema.sql        # DBスキーマ（テーブル・RLS・ストレージ）
└── docs/
    ├── セットアップ手順書_P1.md   # Supabase構築〜公開までの手順
    ├── 本番移行設計書_v0.1.md     # アーキテクチャ・データモデル・フェーズ計画
    └── 利用規約骨子_v0.1.docx     # 弁護士レビュー用ドラフト
```

## セットアップ

`docs/セットアップ手順書_P1.md` に従ってください（所要30〜40分）。概要：

1. Supabaseプロジェクト作成（Tokyo region）
2. `db/cosapo_schema.sql` をSQL Editorで実行
3. `app.html` 冒頭の `CONFIG` にProject URLとanonキーを設定
4. 運営アカウントをadmin昇格 → 動作テスト
5. GitHub Pagesで公開

※`CONFIG` に記載するanonキーは公開前提のキーです（アクセス制御はDB側のRLSが担保）。`service_role` キーは絶対にコミットしないでください。

## 事業ルール（実装に反映済み）

- 学生の掲載・利用は完全無料。手数料は契約成立時に企業から年間契約料の20%のみ
- 18歳以上は個人登録可、高校生は保護者同意必須（同意確認まで非公開）、中学生以下・野球は対象外
- 企業の「チェック」は学生に一切見えない（DB権限レベルで保証）
- 企業と学生の直接連絡は不可。支援相談はすべて事務局経由（中抜き防止・未成年保護）
- 企業の学生閲覧は監査ログに記録
